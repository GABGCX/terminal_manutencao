    Como usar
    
    
    Chegou placa: [2] Placas, cadastre. O banco gera o ID (MP-0001...).
    
    
    Trabalhou: [3] Diário, uma linha por sessão. O status da placa vem daqui.
    
    
    Fechou o diagnóstico: abra a ficha e marque defeito e causa.
    
    
    Trabalho sem placa (bancada, POP, treino): placa GERAL.
    
    
    Papéis: Técnico registra; Leitura só consulta; Admin configura e gerencia usuários.
    
    
    Atalhos fora de campos: 1…8 trocam de aba, N abre novo registro.
    
  
    
  
    
  
    
  
    Dados de exemplo
    
    
    Carrega 12 placas fictícias (IDs EX-01 a EX-12), com histórico, pedidos e conhecimento, para treinar o técnico. Tudo marcado como exemplo e removível com um clique.
    
    
    
  
    
  
    Exportar (backup)
    
    
    Planilhas CSV para abrir no Excel. Faça um backup por quinzena.
